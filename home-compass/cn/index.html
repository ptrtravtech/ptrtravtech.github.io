一、引言

感谢你使用「宜居罗盘」。我们深知个人信息对你的重要性，并将按照《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》等法律法规的要求，遵循合法、正当、必要和诚信原则处理你的个人信息。

本政策适用于宜居罗盘 Android 客户端。请你在使用前仔细阅读，特别是加粗与表格中的内容。你点击「同意并继续」后，本政策即对你生效。

核心摘要：户型图、外景照片、房源档案与罗盘读数只保存在你的手机上， 文字识别也在本机完成，不会上传到任何服务器； 本应用不申请位置权限，不收集你的出生日期； 广告只在你同意本政策后才加载，你可以随时在「设置 - 隐私设置」中撤回同意。

二、我们处理哪些信息

本应用只处理实现功能所必需的信息，具体如下：

信息类型使用场景是否离开你的设备
户型图照片与你的标注生成户型分析报告、自动识别房间名称否，仅在本机处理与保存
外景照片分析窗外、阳台与楼栋外部环境否，仅在本机处理与保存
房源名称、朝向信息整理房源档案、对比多个房源否，仅在本机保存
语言与主题偏好记住你的设置否，仅在本机保存
设备标识（OAID 等）仅在展示广告时由广告 SDK 读取是，详见第五节的广告 SDK

本应用不会收集：你的姓名、手机号、身份证号、通讯录、短信、通话记录、麦克风录音、精确位置，以及你的出生日期。

三、设备权限

权限使用目的与触发时机
相机仅在你主动拍摄户型图或外景时使用，不会在后台开启
相册（读取所选图片）仅在你从相册选择户型图或外景时读取你选中的图片
方向传感器罗盘用它测量朝向，读数只在本机显示，不会上传
网络在展示广告时由广告 SDK 使用

以上权限均在实际使用对应功能时才向你申请，你可以随时在系统设置中关闭。关闭后对应功能不可用，但不影响其他功能。

本应用不申请位置权限，也不在后台读取传感器或相机。

四、本机处理与存储

户型图识别、外景分析与报告生成全部在你的手机上完成。图片、报告、房源档案和设置保存在本应用的私有存储目录中，其他应用无法读取。

删除规则：你在应用内删除某个房源时，该房源关联的报告会一并删除；卸载应用会清除全部本地数据。这些数据只存在于你的设备上，我们无法访问，也无法替你恢复。

本应用不提供账号体系，因此没有「云端备份」，也不需要登录。

五、第三方 SDK 清单

为实现户型文字识别与广告展示，本应用集成了下列第三方 SDK。我们已逐一说明其名称、提供方、使用目的与所处理的信息。

5.1 Google ML Kit 文字识别

  • 提供方：Google LLC
  • 使用目的：读取户型图上印制的房间名称与标注，用于自动为房间打点
  • 处理方式：识别模型随应用一起打包，完全在你的手机上运行；图片不会为了识别而上传到 Google 或任何其他服务器
  • 处理的信息：仅处理你选中的图片像素；不读取设备标识符，不收集账号或位置信息
  • 触发时机：仅在你拍摄或导入户型图后使用；如你从不使用该功能，则不会被调用
  • 隐私政策：policies.google.com/privacy　|　ML Kit 服务条款

5.2 穿山甲广告 SDK

  • 提供方：北京巨量引擎网络技术有限公司
  • 使用目的：展示开屏、横幅、插屏与激励视频广告，以维持本应用免费提供
  • 处理的信息：设备标识符（OAID 等）、设备型号与操作系统版本、网络连接类型、由 IP 地址推断的粗略地理位置、广告展示与点击记录
  • 触发时机：仅在你同意本政策之后才初始化；你选择「仅使用基础功能」或撤回同意后，该 SDK 不会启动，也不会读取任何设备标识
  • 隐私政策：www.csjplatform.com/privacy

5.3 ARCore

  • 提供方：Google LLC
  • 使用目的：在支持的机型上提供增强现实测距与平面识别；不支持的机型自动降级为手动标注
  • 处理的信息：相机画面与运动传感器数据，仅在本机用于空间定位，不上传
  • 隐私政策：policies.google.com/privacy

5.4 系统分享

  • 提供方：你的设备操作系统
  • 使用目的：把你主动选择分享的报告或图片发送到你指定的其他应用
  • 处理的信息：仅传递你选中的内容，不读取其他数据
除上述 SDK 为实现其功能所必需的数据外，本应用不会向任何第三方提供你的户型图、外景照片或房源档案。

六、广告与你的选择

本应用通过穿山甲广告 SDK 展示广告。广告 SDK 可能使用设备标识符为你提供个性化或非个性化广告。

  • 首次启动：我们会先展示隐私政策说明，只有你点击「同意并继续」后，广告 SDK 才会初始化
  • 拒绝的后果：你选择「仅使用基础功能」时，应用的核心功能（户型分析、外景分析、罗盘、房源管理）全部可用，只是不展示广告
  • 撤回同意：你可以随时进入「设置 - 隐私设置」撤回同意，撤回后立即停止加载广告；如需彻底重置，可在系统设置中关闭本应用的「个性化广告」或重置广告标识符

七、你的权利

依据《个人信息保护法》，你对自己的个人信息享有以下权利：

  • 查阅与复制：你的房源档案、报告与标注均可在应用内直接查看
  • 更正与补充：可在应用内随时修改房源信息与标注
  • 删除：在应用内删除房源即可删除对应报告；卸载应用可清除全部本地数据
  • 撤回同意：在「设置 - 隐私设置」中操作，撤回不影响撤回前已进行的处理的效力
  • 注销：本应用无账号体系，卸载应用即视为终止使用，我们不会保留你的任何数据

如你认为我们的处理行为损害了你的合法权益，可通过本政策末尾的方式联系我们，也可以向网信、电信、公安及市场监管等主管部门投诉举报。

八、信息存储与保护

本地数据受设备加密与应用沙箱保护。广告 SDK 传输的数据采用 HTTPS/TLS 加密。我们不会将你的个人信息存储在境外。

本应用不建立用户账号，因此我们不保存可识别你身份的个人信息数据库；一旦发生安全事件，我们会通过应用内公告的方式告知你。

九、未成年人保护

本应用面向成年人，不面向未满 14 周岁的儿童。我们不会主动收集未成年人的个人信息。若你是未成年人，请在监护人陪同下阅读本政策并使用本应用。

十、本政策的更新

当产品功能、第三方 SDK 或法律法规发生变化时，我们会更新本政策，并在应用内以显著方式提示你。若更新涉及你的权利发生实质性变化，我们会重新征求你的同意。
